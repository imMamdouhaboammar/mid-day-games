# يقظة | Yaqadha

يقظة تطبيق عربي قصير الجلسات للقضايا الاستنتاجية وتمارين التركيز. الفكرة ليست زيادة وقت الشاشة، بل تحويل جزء صغير من الاستراحة إلى نشاط يحتاج ملاحظة واستنتاج وذاكرة عاملة.

## ما الذي يقدمه الآن؟

- قضايا عربية تفاعلية مع أدلة ومشتبه بهم وفرضيات للحل
- تمارين قصيرة: ستروب، كشف التناقض، والذاكرة البصرية
- توليد قضايا مخصصة عبر Gemini عند توفير مفتاح API
- سجل محلي للتقدم، النقاط، التتابع اليومي، والقضايا المنجزة
- مؤقت استراحة وأصوات محيطية اختيارية
- تجربة RTL تعمل بدون حساب مستخدم

## التشغيل محليا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

الخصائص الأساسية والقضايا المنسقة تعمل بدون مفتاح API. لتفعيل توليد القضايا والتقييم الذكي:

```bash
cp .env.example .env
# ثم أضف GEMINI_API_KEY
```

## فحوص الجودة

```bash
npm run check
```

يشغل TypeScript checks واختبارات منطق التقدم وبناء نسخة الإنتاج.

## مبدأ المنتج

الجلسة الجيدة هنا قصيرة وواضحة: افتح التطبيق، اختر قضية أو تمرينا، أنه نشاطا واحدا، ثم ارجع لعملك. لذلك أي ميزة جديدة يجب أن تجيب عن سؤالين:

1. هل تجعل الجلسة القصيرة أفضل؟
2. هل القياس المعروض ناتج فعلا من أداء اللاعب أم مجرد رقم تجميلي؟

راجع `PRODUCT.md` و`DESIGN.md` قبل أي تعديل واسع.
